Heavenlee Cookies

Heavenlee Cookies is a responsive cookie ordering website created for a small cookie business that focuses on providing a warm, cozy, and customer-friendly online ordering experience. The website allows customers to browse available cookie flavors, place Cash on Delivery orders, and track their order status online.

The system also includes an owner dashboard where the admin can manage product stocks, monitor customer orders, and update delivery statuses in real time.

Features Customer Side Browse available cookie flavors View product prices and available stocks Add products to cart Place Cash on Delivery orders Track order status Receive automatic order confirmation emails Owner/Admin Side Secure admin login using Firebase Authentication Manage and update stocks Monitor customer orders Update order status in real time Technologies Used HTML CSS JavaScript Firebase Authentication Firebase Firestore EmailJS Netlify Design Concept

The website was designed to match the branding of Heavenlee Cookies by using soft colors, sky-inspired visuals, and a clean interface that gives a warm and comforting feeling. The goal of the design is to create a simple but visually engaging ordering experience for customers while keeping the interface easy to navigate on both desktop and mobile devices.

System Purpose

This project was developed as both a business website and an academic project. It aims to provide a modern ordering platform for Heavenlee Cookies while applying responsive web design, database integration, authentication, and real-time order management.
